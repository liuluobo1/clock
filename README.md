# Clock32 · 透明桌面时钟

> 单文件 · 32 位 · 免安装 · 兼容 Windows 7 / 10 / 11（32 位与 64 位系统都能跑）

双击 `Clock32.exe` 就能用。不需要装 Python、.NET、VC++ 运行库，也不需要联网。

---

## 一、它是什么

贴在桌面上的透明时钟：背景全透明，只留时间和日期，可以拖动、缩放、置顶，
时间颜色会**自动跟着背后的明暗变化**（浅底黑字、深底白字）。

| 特性 | 说明 |
| --- | --- |
| 背景透明 | 完全不遮挡桌面和其他窗口，只有字是实体像素 |
| 两行显示 | 第一行 `HH:MM:SS`，第二行 `2026年11月7日 星期六` |
| 自动配色 | 每 30 秒检测背后颜色，浅底转黑字、深底转白字 |
| 可调颜色 | 菜单里打开系统调色盘，任意指定时间颜色 |
| 细黑框 | 四周 1px 黑线界定范围，可一键关闭 |
| 拖动 / 缩放 | 整窗拖动；右下角黑三角拖动改大小，字号自适应 |
| 托盘常驻 | 右键托盘图标弹出同一套设置菜单 |
| 优先级 | 11 档可选，最高档会主动压制其他置顶窗口 |
| 免安装 | 单个 exe，配置写在旁边的 ini 里，删掉即恢复默认 |

## 二、怎么用

| 操作 | 效果 |
| --- | --- |
| 按住左键拖动 | 移动位置，松手后自动记住坐标 |
| 拖动右下角的小黑三角 | 改变大小，字号自动适配，松手记住尺寸 |
| 右键点时间 | 打开设置菜单 |
| 右键点托盘图标 | 打开同一套设置菜单 |
| 单击托盘图标 | 把时钟提到最前（被挡住时用） |
| 退出 | 菜单 →「退出」 |

### 菜单结构

```
窗口置顶        已开启 / 未开启
────────────
优先级 ...      当前：高（中）
────────────
文字颜色        打开调色盘
显示黑框        点击开关
自动配色        浅底黑字 / 深底白字（每30秒）
重置到左上角
恢复默认大小    也可拖右下角三角
以管理员身份重启 解锁实时档    ← 只在非管理员时出现
关于 Clock32
────────────
退出
```

点「优先级 ...」会原地翻到**优先级页**（11 档 + 「跟随置顶自动切换」+「< 返回」），
选一项立即生效，再点「< 返回」回主菜单。

## 三、自动配色是怎么判的

- **每 30 秒**检测一次时钟**黑框范围内**背后的颜色；
- 计算感知亮度：`0.299R + 0.587G + 0.114B`；
- **亮度 ≥ 140** → 浅色背景 → 时间变**黑**；
- **亮度 ≤ 110** → 深色背景 → 时间变**白**；
- 中间 110~140 的灰色地带**保持不动**，避免在临界值来回闪。

采样点：框内 7×5 均匀分布（四周留 2px 避开黑框），会剔除落在自己字上的点，
剩下取平均；点太少时退回中位数。

> 用调色盘手动选过颜色后，自动配色会自动关闭（免得跟你打架）。
> 想再开就点一下菜单里的「自动配色」。

## 四、优先级档位

菜单「优先级 ...」里共 11 档，实测生效值：

| 档位 | 进程优先级类 | 线程基准优先级 | 备注 |
| --- | --- | --- | --- |
| 默认 | 系统判定 | — | 完全交给系统 |
| 最低（空闲） | IDLE | 6 | 空闲才轮到 |
| 低 | BELOW_NORMAL | 2 | 让 CPU 给别人 |
| 低于正常 | BELOW_NORMAL | 8 | 桌面卡顿也不添乱 |
| 正常（中） | NORMAL | 8 | 系统默认 |
| 高于正常 | ABOVE_NORMAL | 10 | 通常安全的偏高档 |
| 高 | HIGH | **26** | 免提权实际最高 |
| 高·强化 | HIGH | 26 | 再退掉节能节流、计时精度 0.5ms |
| 实时 | REALTIME | **31** | 需管理员，无权限时到 26 |
| 实时·强化 | REALTIME | 31 | 实时 + 强化 |
| 实时·满功率 | REALTIME | 31 | 再加快抢 Z 序，约吃 82% 一个核 |

要点：

- **26 是普通权限的物理上限**。`HIGH` 类里线程最高只有 15，程序改用 MMCSS
  （多媒体类调度服务）的临界档拿到 26；再往上 31 必须有管理员权限。
- 置顶开启时会自动抢 **Z 序**（每秒上千次把自己重新排到最前），
  实测对手每 1ms 抢一次也能压住。
- 「实时·满功率」最狠但费 CPU，笔记本会明显发热，按需使用。

## 五、配置文件

程序同目录下的 `Clock32.ini`（写不进去时改用注册表 `HKCU\Software\Clock32`）：

```ini
[Clock32]
Topmost=0        ; 是否置顶
Priority=4       ; 当前档位（0默认 1最低 2低 3低于正常 4正常 5高于正常
                 ;            6高 7实时 8高·强化 9实时·强化 10实时·满功率）
AutoTier=1       ; 档位是否跟随置顶自动切换（手动选档后变 0）
X=20             ; 窗口位置
Y=20
W=213            ; 窗口尺寸（拖过右下角三角才有；0 = 按字体自然大小）
H=106
Color=0          ; 时间颜色（COLORREF 0x00BBGGRR，0 = 纯黑）
Border=1         ; 是否画四周细黑框
AutoColor=1      ; 自动配色开关
LastLum=234      ; 最近一次检测到的背景亮度（仅供排查，改它没用）
Version=103
```

想恢复出厂状态：**删掉 `Clock32.ini` 再启动**即可。

## 六、兼容性

- **32 位程序**（`Machine = 0x14C`），32 位和 64 位 Windows 都能直接跑；
- 只依赖系统自带的 `kernel32 / user32 / gdi32 / advapi32 / shell32 / comdlg32 / msvcrt`；
- **不依赖 UCRT**（Win7 原生没有），Windows 7 无需装任何补丁即可运行；
- 高优先级（MMCSS）等 API 都是**动态加载**，系统不支持就自动降级，不会启动失败；
- 单实例：重复双击不会开出第二个钟，只会把已有的提到前面。

## 七、常见问题

**Q：时间颜色不变？**
先确认菜单里「自动配色」是勾选状态；再想想是不是手动用调色盘选过颜色（那会自动关闭自动配色）。
另外 ini 里的 `LastLum` 是最近一次检测到的背景亮度——如果它一直是同一个数，
说明时钟所在位置的背景确实没变。

**Q：黑框关了会影响自动配色吗？**
不会。采样点在框内 2px 处，和黑框是两条独立路径。

**Q：为什么最高只到「26」不是 31？**
31 需要 Windows 的实时优先级类，普通权限拿不到。用菜单里的
「以管理员身份重启」后，再选「实时」档就是真正的 31。

**Q：置顶了还是被别的窗口盖住？**
先确认置顶已开启（菜单第一项打勾）。程序会持续抢 Z 序，
但如果对方是**独占全屏游戏**，任何用户态程序都盖不过去（那需要驱动级叠加层）。

**Q：拖到屏幕外找不到了？**
菜单 →「重置到左上角」。

**Q：桌面上有两个 Clock32 的 exe？**
`Clock32.exe` 和 `Clock32最高优先级版本.exe` 内容相同，留一个就行，
另一个可以删掉，避免重复启动时互相抢单实例。
